VoiceGrepmacOS 14.4+ · v1.9 · 100% local

Call transcripts, right on your Mac.

Records two tracks: your microphone and the call audio. After the call, it transcribes the recording on-device and labels who said what. It recognizes people by voice — you only need to name each one once. Nothing is sent to the cloud.

ImpAgentmacOS & Windows · MCP · your own model

Jira, Jenkins and Bitbucket in one window with an agent.

A chat with the model, files, shell and git, with Jira, Confluence, Bitbucket, Jenkins, TestOps and Kubernetes right alongside. The agent gathers the task context itself and proposes changes one at a time, each with a diff and a confirmation. Over MCP, the same tools work in Cursor, Claude Code and Codex.

SeatkeymacOS · Apple Silicon · OpenAI / Anthropic API

Your Claude Code subscription instead of an API key.

Obsidian, Raycast, Open WebUI and your own scripts ask for an OpenAI API key. Seatkey serves a compatible endpoint on 127.0.0.1 and answers through Claude Code, Codex or Cursor — on the subscription you already have. No separate key, no second bill.
