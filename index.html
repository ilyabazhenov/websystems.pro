HopkeymacOS 13+ · v1.7 · бесплатно · open source

Двойной ⌘ — и всё мелкое уже под рукой.

SeatkeymacOS · Apple Silicon · OpenAI / Anthropic API

Подписка на Claude Code вместо API-ключа.

Mac в другой комнате. Его окна — в руке.
